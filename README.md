# CRUD Node.js con Express y MySQL

Este proyecto es una aplicación CRUD (Crear, Leer, Actualizar, Eliminar) desarrollada con Node.js. Está diseñada para gestionar registros de manera eficiente, proporcionando una API RESTful.

## 🚀 Tecnologías Utilizadas

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [Nodemon](https://nodemon.io/) (para desarrollo)
- [Fs](https://nodejs.org/docs/v0.3.1/api/fs.html)
- [Path](https://nodejs.org/api/path.html)

## 📁 Requisitos del Proyecto

- Contar con npm
- Contar con alguna app que consuma API Rest, como Postman


## ¿Cómo usar el proyecto?

- Clonar el repositorio
  ```
  git clone https://github.com/JoakoSavini/crud_nodejs
  cd crud_nodejs
  ```
- Instalar depedencias
  ```
  npm install
  ```
- Correr el proyecto
  ```
  npm run dev
  ```
- Listo para probar! el frontend del proyecto lo podes encontrar en https://github.com/JoakoSavini/proyecto-crud
